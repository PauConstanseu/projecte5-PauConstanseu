# 🗂️ Introducció

Aquesta tasca és la continuació natural del treball realitzat prèviament amb la instal·lació i configuració inicial del servidor Windows Server 2025. Ara, el següent pas és desplegar el **Directori Actiu (Active Directory Domain Services)** sobre la màquina virtual preparada. Aquest procés és fonamental per entendre el funcionament de la infraestructura de dominis, així com el paper crític que exerceix un controlador de domini dins d’una organització.

L’objectiu principal és crear un entorn completament funcional que serveixi com a **prova de concepte (PoC)** per presentar a **TransLògic**. Aquesta PoC permetrà validar la viabilitat del disseny proposat, revisar que les configuracions són alineades amb les necessitats del client i ajustar qualsevol paràmetre abans de realitzar el desplegament definitiu als sistemes corporatius.

Durant aquesta pràctica es documentaran totes les fases del procés: instal·lació dels rols necessaris, configuració del nou domini, establiment del nivell funcional i promoció del servidor com a controlador de domini. A més, es generarà l’script PowerShell corresponent, que demostrarà com es pot automatitzar tot aquest procediment en un entorn real.

Aquesta documentació i la PoC resultant constituiran una base sòlida per assegurar que el futur desplegament en TransLògic sigui segur, eficient i perfectament adaptat al seu entorn empresarial.
